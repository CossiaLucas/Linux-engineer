# Historia

Podriamos contar un poco toda la historia de linux, pero ese no es el foco principal de todo. 
Mas, si vamos a hacer un foco en aspectos importantes para su nacimiento como UNIX, GNU, y despues ya podemos a pasar a aspectos mas importantes, como el kernel.

## UNIX

UNIX es una familia de sistemas operativos.
La primera versión fue creada entre 1969 y 1970
en el centro de investigación de Bell Labs. fe bastante importante en su momento porque implemento distintas funcionalidades bastante novedosas para la epoca.
Algunas como:
* La multitarea
* La posibilidad de ser usado por distintos usuarios al mismo tiempo
Asi como tambien agrego otros conceptos importantes como:
* Sistema de archivos jerarquicos
* Una shell que permitia ingresar comando y programar scripts
* Uso de archivos de texto para la configuracion

## Proyecto GNU

Se trata de un proyecto colaborativo de software libre fundado por *Richard Stallman* en 1983 con el objetivo de crear un sistema operativo completamente libre similar a Unix
* Busca dar control a los usuarios sobre sus ordenadores mediante software que se puede usar, copiar, modificar y redistribuir.
* **Las cuatro libertades:** Incluyen ejecutar el programa (libertad 0), estudiar y modificar el código (libertad 1), redistribuir copias (libertad 2) 
y estudiar cómo funciona el programa y modificarlo para adaptarlo a las propias necesidades. (libertad 3).
* **Copyleft y GPL:** Creó licencias como la Licencia Pública General de GNU (GPL) para garantizar legalmente que estas libertades se mantengan en cualquier obra derivada.

El proyecto desarrolló muchas herramientas del sistema (compiladores, editores, comandos), pero le faltaba un núcleo (kernel) funcional. 

### Kernel

El núcleo (en inglés: kernel) es un programa fundamental de cualquier sistema operativo,
ya que determina el uso de memoria RAM, conexiones de red, el control de hardware y así
como la interacción con el resto del software. O en otras palabras actúa como intermediario entre el hardware y los programas

## El nacimiento de linux
*Linus Torvalds* comenzó a desarrollar Linux sobre el
sistema operativo Minix, en el 1991. Poco tiempo después, reemplaza las herramientas Minix existentes por
las desarrolladas en el proyecto GNU. A finales de 1991 se hizo público Linux con la
versión 0.10. Un mes después, en diciembre, apareció la versión 0.11 y Linus animó a otras
personas a colaborar en su desarrollo. En enero de 1992, el sistema operativo dio un paso
significativo, pues salió la primera versión - 0.12 - con la licencia de software libre GNU GPL.

Linux originalmente es el kernel, no todo el sistema operativo. 
Cuando hablamos de una distribución GNU/Linux estamos hablando del kernel Linux junto con las herramientas del sistema, bibliotecas, paquetes, servicios, instalador, etc.
