# 01 - Introducción a Linux

Primer curso de la carrera **Linux Engineer**, orientado a adquirir los fundamentos necesarios para trabajar con sistemas Linux y comprender las tareas básicas de administración.

## 🎯 Objetivos

* Comprender los conceptos fundamentales de Linux.
* Familiarizarme con el entorno de trabajo y la terminal.
* Conocer la estructura del sistema de archivos.
* Administrar archivos y directorios mediante comandos.
* Comprender usuarios, grupos y permisos.
* Conocer la gestión básica de procesos y servicios.
* Realizar tareas básicas de administración desde la línea de comandos.

## 📚 Contenidos

### 01 - Conceptos de Linux

* ¿Qué es Linux?
* Kernel y distribución.
* Distribuciones Linux.
* GNU/Linux.
* Arquitectura básica del sistema.
* Entorno de usuario y shell.

### 02 - Instalación

* Instalación de una distribución Linux.
* Configuración inicial.
* Particionado y sistema de archivos.
* Configuración de red.
* Actualización del sistema.
* Instalación de paquetes.

### 03 - Terminal y comandos

* Uso de la terminal.
* Navegación por el sistema de archivos.
* Gestión de archivos y directorios.
* Búsqueda de archivos.
* Redirecciones y pipes.
* Variables de entorno.
* Comandos básicos de administración.

### 04 - Sistema de archivos

* Estructura de directorios de Linux.
* Rutas absolutas y relativas.
* Montaje de dispositivos.
* Permisos sobre archivos y directorios.
* Espacio disponible y uso del almacenamiento.

### 05 - Usuarios y permisos

* Usuarios y grupos.
* Creación y modificación de usuarios.
* Gestión de grupos.
* Permisos de archivos.
* `chmod`, `chown` y `chgrp`.
* Permisos especiales.

### 06 - Procesos y servicios

* Procesos.
* Identificación y gestión de procesos.
* Servicios del sistema.
* Inicio y detención de servicios.
* Conceptos básicos de `systemd`.

## 🧪 Prácticas

Las prácticas realizadas durante el curso se encuentran organizadas en las diferentes secciones del repositorio.

Algunos ejemplos:

* Instalación y configuración inicial de Linux.
* Creación y administración de usuarios.
* Gestión de permisos.
* Administración de archivos y directorios.
* Gestión de procesos.
* Administración básica de servicios.
* Prácticas mediante terminal.
