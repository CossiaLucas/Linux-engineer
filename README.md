# Linux Engineer

Repositorio donde documento mi formación y prácticas realizadas durante la carrera corta **Linux Engineer** de EducaciónIT.

El objetivo de este repositorio es registrar de manera organizada los conocimientos adquiridos sobre **Linux, administración de sistemas, scripting, servidores, redes y automatización**, incluyendo prácticas, ejercicios, configuraciones y documentación técnica.

| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| [01 - Introducción a Linux](./01-introduccion-linux/) | Fundamentos de Linux, instalación, terminal, sistema de archivos, usuarios, permisos y administración básica. |
| 02 - Linux SysAdmin                                   | Administración y gestión de sistemas Linux.                                                                   |
| 03 - Shell Scripting                                  | Automatización de tareas mediante Bash y Shell Scripting.                                                     |
| ...                                                   | Próximamente                                                                                                  |

## 🎯 Objetivos

* Comprender el funcionamiento y la administración de sistemas Linux.
* Adquirir experiencia práctica mediante laboratorios y ejercicios.
* Automatizar tareas utilizando Shell Scripting.
* Comprender conceptos de servidores, redes e infraestructura.
* Documentar procedimientos técnicos de forma clara y reproducible.
* Construir una base orientada a roles de **SysAdmin, Infraestructura y Soporte IT**.
